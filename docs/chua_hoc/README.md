# Kho kiến thức chưa học

Nội dung do claude.ai soạn sẵn cho bài toán bám mục tiêu, **người học chưa tìm hiểu**. Giữ ở đây để Claude Code dạy dần từng phần theo yêu cầu. Khi một phần đã học xong và đã hỏi lại, chuyển sang `docs/` và ghi vào mục lục chính.

| File | Nội dung | Gắn với bước lộ trình |
|---|---|---|
| [toan_phu_tro.md](toan_phu_tro.md) | Pytago, bearing (atan2), phép `%`, công thức góc xoay | Phân tích số liệu thí nghiệm (bước 1) |
| [thi_giac_phat_hien_theo_doi.md](thi_giac_phat_hien_theo_doi.md) | YOLO, IoU, tracking, mô hình camera, visual servoing | Bước 3, 4 |
| [du_doan_va_kalman.md](du_doan_va_kalman.md) | Dự đoán quỹ đạo, Kalman filter | Bước 5 |
| [bam_nguoi_dam_dong.md](bam_nguoi_dam_dong.md) | Re-ID, chống nhảy ID, che khuất, hai người giống hệt nhau | Bước 5 |
| [thuat_ngu.md](thuat_ngu.md) | Thuật ngữ của các phần trên | |

Chưa có file cho: bộ điều khiển P (sẽ viết trong `docs/` khi người học bắt đầu học).
